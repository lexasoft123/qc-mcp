Patchbay 0.3.0 — find tones in Cortex Cloud, save with confidence

Sign in to Cortex Cloud in Patchbay or the terminal and use the same session from your MCP client. Search for presets and captures, then queue them for your Quad Cortex to download. On the device, Patchbay keeps track of which preset it is leveling and checks that each save reached the intended slot.

## Cortex Cloud

- Choose **Cloud** in Patchbay to sign in, or run `qc-mcp cloud login` in the terminal. Patchbay and MCP share the session on macOS and Windows. MCP can use it while Patchbay is closed or the Quad Cortex is unplugged.
- Search presets, captures, and profiles through MCP. Queue downloads, then let your Quad Cortex or Cortex Control sync before loading the content.
- The Cloud tools can also edit metadata and change publishing state for captures your account owns.

See the [Cortex Cloud guide](https://github.com/lexasoft123/qc-mcp/blob/v0.3.0/docs/CORTEX-CLOUD.md).

## Presets and leveling

- Saves check the active preset and the destination on the device. Occupied slots require explicit overwrite. Patchbay verifies the saved entry before marking a row saved.
- **Measure Scenes** waits for the selected scene. Skipped and unselected scenes keep their trims. **Stop** ends a batch after the current measurement.
- **Apply All**, **Save All**, and per-row **Undo** follow the active preset and keep the correct baseline when you revisit a row.
- Recall checks both the setlist and the slot. Preset readback shows capture bindings and per-scene values and bypass states.

## Compatibility

- Patchbay installers are available for Windows and for Apple silicon and Intel Macs. The standalone MCP server also supports direct USB HID on Linux.
- If an existing macOS bridge reports that its identity is unavailable, rebuild and restart the interposer so it can read the app's startup identity.
- Measured leveling requires the optional Python audio dependencies. See the [leveling guide](https://github.com/lexasoft123/qc-mcp/blob/v0.3.0/docs/LEVELING.md).
