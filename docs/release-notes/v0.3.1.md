Patchbay 0.3.1 — Cortex Cloud browsing and more accurate meters

This update completes the Cortex Cloud workflow from 0.3.0 and fixes plugin preset recall and output meter readings.

- **Cortex Cloud in Patchbay.** After signing in, search for presets and Neural Captures. Expand a result to see its metadata and, for presets, compatibility, blocks, and scenes. The MCP tools now check ownership correctly when you edit, publish, unpublish, or delete your own captures. [#42](https://github.com/lexasoft123/qc-mcp/pull/42)
- **Plugin preset recall.** Use the exact key returned by the device catalog. Recall now reports an error if a plugin key loads an empty grid. [#44](https://github.com/lexasoft123/qc-mcp/pull/44)
- **Output meters.** Patchbay and the MCP output meter now use the measured device dB scale. The MCP output also lists ports whose peaks exceeded full scale. [#45](https://github.com/lexasoft123/qc-mcp/pull/45)

Installers are available for Windows x64 and for Apple silicon and Intel Macs.
